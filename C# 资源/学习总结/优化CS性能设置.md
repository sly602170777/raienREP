# 优化CS速度

```
★　 自動ファイル復元を無効にする
[ツール]>[オプション] >[プロジェクトおよびソリューション]>[全般] > [ソリューションの読み込み時にドキュメントを再度開く] の選択を解除します。

```

```
★　デバッグ オプションを構成する
・マイコードのみを有効にする
 [ツール]>[オプション]>[デバッグ]>[全般] の順に選択し、 [マイ コードのみを有効にする] をオンにします。

 ・読み込むシンボルを指定する
 [ツール]>[オプション]>[デバッグ]>[シンボル]>
 [デバッグ]>[Windows]>[モジュール] の順に選択します

 ・診断ツールを無効にする
  [ツール]>[オプション]>[デバッグ]>[全般]
  [デバッグ中に診断ツールを有効にする] オプションをオフにします

・CodeLens を無効にする
 [ツール]>[オプション]>[テキスト エディター]>[すべての言語]>[CodeLens] の順に選択し、この機能をオフにします。
```

```
★　ガベージ コレクションを強制する

キーボード ショートカット Ctrl+Alt+Shift+F12 キー、Ctrl+Alt+Shift+F12 キー (2 回押します) を使います。
```
